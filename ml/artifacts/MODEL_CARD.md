# FireWatch — Карточка модели (Model Card)

**Версия:** `xgboost-1.0` · **Алгоритм:** XGBoost (binary:logistic) + Platt-калибровка · **Объяснимость:** TreeSHAP

## Назначение
Оценка риск-приоритета здания (0–100) для приоритизации надзорных проверок ДЧС РК. Не заменяет инспектора — ранжирует объекты по риску. Помимо вероятности возгорания учитывает функциональную пожарную опасность объекта (массовое пребывание людей, маломобильные/дети/стационар, категория производства А–Д, газоснабжение), поэтому это приоритет надзора с учётом тяжести последствий, а не чистая вероятность возгорания — в духе риск-ориентированного надзора РК.

## Данные обучения
Источник: `synthetic`. Текущая сборка обучена на синтетическом наборе с фиксированным seed (плейсхолдер до передачи исторических данных ДЧС). Контракт признаков и пайплайн идентичны для реальных данных — см. `train/dataset.py::from_incidents`.

## Метрики на отложенной выборке (test)
- **ROC-AUC:** 0.8147
- **PR-AUC:** 0.535
- **Brier (до/после калибровки):** 0.1117 → 0.1118
- **Базовая частота события:** 0.1778
- **Lift @10%:** 3.5× (захват 35% пожаров в топ-10% риска)
- **Lift @20%:** 2.828×

## Гейт качества
Сборка падает, если ROC-AUC < 0.78. Плохая модель не доедет до прод.

## Ограничения
- Синтетический ground truth ≠ реальная пожарная статистика; цифры подтверждают работоспособность пайплайна, не оперативную точность.
- Перед боевым применением — переобучение на данных ДЧС и валидация на ретроспективе (out-of-time).
