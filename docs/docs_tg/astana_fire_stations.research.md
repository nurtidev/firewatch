# Пожарно-спасательные части г. Астаны — сверка с FireWatch (2026)

Проверка по запросу: «частей больше 4, адреса неправильные». **Подтверждено.**
Источник машиночитаемых данных: [`api/scripts/seed_data/astana_fire_stations.json`](../../api/scripts/seed_data/astana_fire_stations.json).

> ⚠️ Данные собраны из открытых справочников (2ГИС / JSprav / Zoon / «Вечерняя
> Астана»), **это не официальный перечень ДЧС**. Часть адресов подтверждена
> одним источником; координаты заполнены только там, где есть карточка 2ГИС.
> Перед пилотом сверить с официальным списком ГУ «СПиАСР» ДЧС г. Астаны.

## Итог

- В Астане **≥13 действующих** пожарно-спасательных частей (по нормативу нужно ~30), **не 4**.
- В коде FireWatch фигурируют лишь 5–6 (ПЧ-1, СПЧ-2, ПЧ-6, ПЧ-8, ПЧ-10, ПЧ-11) — **>50% частей отсутствуют**.
- Адреса/координаты ПЧ **не зашиты** — станции тянутся из OSM, который по Астане
  неполный (`import_infra.py` предупреждает об этом сам). Карта покрытия недостоверна.

## Достоверность по частям

- **Высокая** (карточка 2ГІС/несколько источников): СПЧ-1, СПЧ-2, СПЧ-3*, СПЧ-4, СПЧ-6, ПЧ-10*, ПЧ-17*, ГУ СПиАСР. (`*` — есть координаты)
- **Средняя** (один источник): СПЧ-5, ПЧ-8, СПЧ-16, ПЧ-23, СПЧ-24.
- **Низкая**: ПЧ-7.

## Что НЕ сделано (намеренно)

- **Координаты не выдуманы**: на карту можно ставить пока только 3 части (ПЧ-10,
  ПЧ-17, СПЧ-3). Остальным нужен геокодинг адресов или официальные координаты ДЧС.
- **import_infra.py не трогался** — fallback на seed добавим, когда подтвердим список.
