# docs_tg — исходные материалы (ДЧС, ПТП/оперативный план)

Сканы и документы реального оперативного плана пожаротушения (ПТП) для **ЖК «Хайвилл-Астана»**
(г. Нур-Султан, ПЧ-10). Используются как первый реальный объект (оперативная карточка + 2D/3D тестовые данные) в FireWatch.

В каталоге две редакции одного объекта:
- **2007 г.** — оригинальный «ОПЕРАТИВНЫЙ ПЛАН» (текстовый, машиночитаемый): `Хайвилл Астана.pdf` / `Хайвилл Астана.docx`. Адрес «г. Астана», блоки А/Б/C/Д + детсад.
- **2020 г.** — переоформленный «ПЛАН ТУШЕНИЯ ПОЖАРА» (сканы `57.*`): г. Нур-Султан, блоки A/B/C/D/E1/E2/F/G, обновлённые телефоны и адреса. Структура по 8 разделам.

Извлечённые структурированные данные: **`hayvill.extracted.json`**.
