# FireWatch — Анализ рынка и конкурентов

> Для инвесторов и как аргументация в КП для ДЧС. Составлен 2026-07-02 по
> веб-разведке (источники — ссылками). Честно помечены оценочные/слабые данные.

## Вывод одной строкой

Общий рынок пожарной безопасности огромный, но «железный». **Узкая ниша
FireWatch — ИИ-предиктивная риск-аналитика + оцифровка планов для
государственной пожарной службы — в мире практически пуста как продукт**, при
этом подход уже научно доказан на реальных городах США. В СНГ и Центральной
Азии прямых аналогов не найдено.

| Услуги пожарной безопасности | ~$162 млрд | CAGR 4.1% → $242 млрд к 2036 | [Fact.MR](https://www.factmr.com/report/fire-safety-services-market) |
| ИИ-предиктивная риск-аналитика для пожарных служб | **не оценён** | — | нет как рынка продуктов |

**Честно:** большой рынок ($75–87 млрд) — это оборудование, не наш продукт.
Наш реальный адресуемый рынок — услуги (аудит, документация, инспекции) +
госбюджеты на цифровизацию пожарных служб. Отдельного TAM для «ИИ-предиктивной
пожарной аналитики» пока нет — это и риск (нет готовой цифры для инвестора), и
возможность (whitespace).

## 2. Конкуренты — 4 группы, и все мимо нашей ниши

### A. Insurtech: риск пожара для страховщиков (не для пожарных служб)

| Компания | Что делает | Финансирование |
|---|---|---|
| [ZestyAI](https://www.zesty.ai) | «цифровые двойники» зданий, скоринг риска (Z-FIRE, Z-SPARK) | ~$46M, Series B $33M (2022) |
| Cape Analytics | геопространственный ИИ по аэроснимкам для андеррайтинга | ~$75M |
| Betterview | risk-intelligence по имиджери | куплен Nearmap (2023) |
| Arturo | property analytics (спинаут AmFam) | ~$47M, свернулись (2025) |

Доказывают, что «двойник + риск пожара» — фандебельная тема, но продают
**страховым компаниям**. Прямого гос/пожарного применения нет ни у кого.

### B. Софт для пожарных служб — но это диспетчеризация, не предсказание

| Компания | Что делает | Финансирование |
|---|---|---|
| First Due | RMS/расписания/инспекции/пре-планы | **$355M** (JMI Equity) |
| ESO Solutions | облачный CAD/RMS + PrePlan | $65.1M, выкуп d2i (2026) |
| Mark43 | CAD/RMS для police/fire/EMS | $219M+ |
| RapidSOS | обогащение данных 911/CAD | >$450M |
| Prepared | ИИ для приёма звонков 911 | куплен Axon за **$640M** (2025) |

Крупные деньги — но это учёт вызовов и ресурсов. **Предиктивной риск-модели
здания у них нет.**

### C. Оцифровка планов / цифровые двойники — единственный близкий конкурент

- **[Mappedin](https://www.mappedin.com/industries/fire-departments/)** (Series B
  $24.5M) — ИИ автоматически оцифровывает планы этажей в 3D за 0.5–3 мин, есть
  продукт «для пожарных департаментов». **Самый близкий аналог нашему Модулю 03.**
  Но: про indoor-карты, США, **без предиктивной риск-модели**.
- First Due, ESO PrePlan, Station Boss, APX Data, Locatrix — просто
  хранилища/просмотрщики пре-планов, без ИИ-оцифровки сканов.

### D. Академия и гос-пилоты — концепт ДОКАЗАН (наш главный аргумент)

| Проект | Результат | Источник |
|---|---|---|
| **Firebird** (Атланта, KDD 2016) | ML-риск 5000+ зданий, **TPR 71.4%** при FPR 20%; 6096 новых объектов; best practice NFPA | [PDF](https://poloclub.github.io/polochau/papers/16-kdd-firebird.pdf) |
| **FDNY FireCast** (Нью-Йорк) | ~350K зданий, до 7500 факторов из 17 агентств; 16.5% пожаров — в зданиях, инспектированных за 90 дней | [GovTech](https://www.govtech.com/public-safety/new-york-city-fights-fire-with-data.html) |
| **DC Fire & EMS** (2025, RCT) | модель предсказывала пожары, но инспекторы **не нашли больше нарушений** — важный урок | [отчёт](https://static1.squarespace.com/static/5d2361aa11fed60001f7ab3a/t/6903a3f975af8d58a9d59b2d/1761846265442/Predicting-Fire-Risk-Evaluation-Report-Oct2025.pdf) |
| **CMU Metro21** (Питтсбург) | риск-дашборд для пожарного бюро | [CMU](https://www.cmu.edu/metro21/projects/smart-infrastructure/fire-risk-analysis.html) |
| GIS+ML размещение частей | охват улучшался **с 63% до 88%** — аргумент для Модуля 05 | [MDPI](https://www.mdpi.com/2220-9964/14/6/229) |

Академический консенсус: **XGBoost/ансамблевые методы стабильно выигрывают** на
задаче риска пожара ([MDPI](https://www.mdpi.com/2571-6255/7/10/336),
[ACM 2024](https://dl.acm.org/doi/10.1145/3708360.3708367)) — то есть наш стек
не случайность, а мейнстрим.

## 3. Позиционирование FireWatch

**Уникальность:** предиктивная риск-карта + ИИ-оцифровка планов + планирование
инспекций + анализ слепых зон, собранные в **один продукт для национальной
пожарной службы**. Каждый кусок существует по отдельности (Firebird — модель,
Mappedin — оцифровка, ZestyAI — двойник), но собранного продукта для
госпожарной службы аналога не найдено.

- **Гос-прецеденты = козырь.** «Технология дала 71% точности в Атланте и
  работает в FDNY; мы делаем то же для Казахстана, но как готовую платформу, а
  не разовый научный проект».
- **СНГ/ЦА — чистое поле.** Похожих продуктов на постсоветском пространстве не
  найдено.

## 4. Две честные оговорки

1. **Модель сейчас на синтетике.** 71% как в Атланте достижимы только с
   реальными данными ДЧС — ещё один довод, зачем нужен LOI и доступ к данным.
2. **Урок DC:** обещай «предсказание и приоритизацию пожаров», а не «больше
   выявленных нарушений» — иначе рискуешь не подтвердить эффект.

## 5. Что НЕ приписывать себе

Не заявляй «рынок $87 млрд» — это рынок оборудования. Адресуемый рынок —
услуги + госбюджеты на цифровизацию, он меньше и его надо считать снизу
(число объектов × цена лицензии/пакета).
