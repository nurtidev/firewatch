## Две дороги к деньгам
- **Трек А (государство):** LOI → платный пилот 3.9 млн ₸ → годовой контракт
  24 млн ₸/год. Долго, крупно, требует данных и (для оплаты) аттестации.
- **Трек Б (частники, Модуль 03):** оцифровка ПТП от 90К ₸/объект. Без
  тендера и аттестации — деньги через недели, уже на текущем прототипе.

## Ближайшие 3 действия (не код)
1. Оформить/подтвердить ТОО или ИП для приёма платежей (блокирует всё).
2. Замерить себестоимость 1 объекта трека Б на Хайвилле → зафиксировать цену.
3. Отправить КП + план пилота + LOI в ДЧС Астаны и назначить встречу.
